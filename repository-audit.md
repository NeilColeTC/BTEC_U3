# Whole-Repository Completion Audit

## Audit scope

This audit reviewed the 17-week teaching sequence, repository-level curriculum and assessment documentation, weekly resource structure, DojoLearn integration and alignment with the Unit 3 assessment criteria.

## Critical findings resolved

### 1. Week 9 was still a scaffold

Week 9 had only a short README while Weeks 1–8 and 10–17 had full resource packages. It has now been fully developed with lesson plan, slides, learner activities, DojoLearn drafting activity, teacher resources and B.P3/B.M2 checks.

### 2. BC.D2 / BC.D3 distinction needed correction

The repository-level criteria map correctly states:

- **BC.D2:** evaluate the plan and use of social media in a business against business requirements.
- **BC.D3:** demonstrate individual responsibility, creativity and effective self-management in planning and using social media in a business context.

Several later-week resources had drifted towards treating BC.D3 as the final campaign-evaluation criterion. The course map and key Week 11/13/15/16/17 resources have been corrected so evaluation sits under BC.D2 and professional-behaviour evidence is accumulated for BC.D3.

### 3. Repository-level support material was lighter than BTEC_U18

The repository now includes a resource index, global terminology, teacher delivery guide, assessment boundaries, Assignment 1/2 grading-readiness checklists and reusable learner templates.

### 4. DojoLearn integration confirmed

The DojoLearn repository contains the simulation platform configuration and simulation dashboard/controller resources, including the named simulated platforms. Unit 3 resources therefore retain DojoLearn as the controlled practical environment.

## Maintenance recommendations

1. Re-check DojoLearn capability wording if the simulation changes materially.
2. Re-check Pearson/centre assessment guidance before each new delivery year.
3. Update examples of real commercial platforms and audience data annually because social-media platforms evolve rapidly.
4. Keep neutral formative scenarios distinct from live assignment evidence.
5. Preserve BC.D3 evidence throughout practical work rather than relying on retrospective learner claims.

## Audit outcome

The repository is structurally complete for delivery. Future work should be maintenance, refinement and optional production tooling rather than creation of missing curriculum weeks.
