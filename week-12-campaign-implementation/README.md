# Week 12 — Campaign Implementation

**Specification focus:** Learning Aim C — C1/C2  
**Assessment preparation:** C.P5  
**Practical environment:** DojoLearn social-media simulation

## Week purpose

Week 12 moves learners from the reviewed campaign plan into controlled implementation. Learners configure professional simulated business profiles, apply branding consistently and begin publishing campaign content in line with the refined plan created during Learning Aim B.

The central implementation cycle is:

**refined plan → configure → quality check → publish → capture evidence → compare with plan**

## Learning outcomes

Learners should be able to:

1. Translate the refined campaign plan into an operational DojoLearn setup.
2. Configure professional business-profile information using available simulator features.
3. Apply planned branding and communication style consistently.
4. Prepare and quality-check content before publication.
5. Publish campaign content according to the planned purpose, audience and schedule.
6. Maintain traceability between each significant implementation action and the campaign plan.
7. Capture reliable implementation evidence for C.P5 and later evaluation.
8. Record justified deviations rather than silently changing the plan during implementation.

## C1/C2 focus

This week concentrates on professional profile configuration, consistent branding and the initial implementation/publishing of planned campaign content.

## DojoLearn practical

The majority of the session is an implementation workshop across the learner's selected simulated platform(s). Learners configure the campaign environment, quality-check planned content, publish the appropriate first campaign activity and maintain an evidence/implementation log.

## Assessment boundary

Implementation must remain the learner's own work. Support should focus on simulator operation, quality-control processes and evidence capture rather than rewriting campaign content or making assessed implementation decisions for the learner.
