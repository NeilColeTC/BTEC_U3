# Week 12 Key Terminology

| Term | Working definition | Why it matters |
|---|---|---|
| Implementation | Putting the reviewed campaign plan into operation. | C.P5 requires evidence of the campaign being created/operated rather than merely planned. |
| Business profile | Organisational identity/profile presented on a social platform. | Establishes who the campaign represents. |
| Configuration | Setting available profile/campaign options to match the plan. | Connects planning decisions to the operational environment. |
| Branding | Consistent identity expressed through visual choices, tone, messages and other brand elements. | Helps the campaign appear coherent and recognisable. |
| Tone of voice | Style/personality used in written communication. | Should suit the business, audience and campaign purpose. |
| Publication | Making campaign content live/available within the simulation. | Creates observable implementation and later performance evidence. |
| Quality assurance | Checks performed to reduce errors and confirm work meets requirements before release. | Prevents avoidable implementation problems. |
| Pre-publication check | Structured review immediately before content is published. | Protects quality, policy compliance and traceability. |
| Traceability | Ability to connect implemented activity to planned requirements/objectives and evidence. | Essential for showing that the campaign implements the plan. |
| Implementation evidence | Records showing what was actually configured, published or operated. | Supports C.P5 and later evaluation. |
| Evidence log | Organised index of implementation evidence and what each item demonstrates. | Avoids disconnected screenshot collections. |
| Evidence annotation | Short explanation of what an evidence item shows and why it is relevant. | Makes evidence interpretable. |
| Deviation | Significant difference between refined plan and actual implementation. | Needs explanation so change does not break traceability. |
| Change control | Process of recording and managing implementation changes. | Supports professional and evaluative practice. |
| Baseline | Recorded starting state before campaign activity. | Allows later comparison with performance. |
| Campaign target | Intended performance level for a relevant measure. | Provides a reference for monitoring/evaluation. |
| Platform-specific adaptation | Adjusting presentation to suit a platform while retaining campaign purpose/identity. | Supports appropriate implementation without unnecessary duplication. |
