# Week 12 — Assessment and Understanding Checks

## Criteria progression

**C.P5:** implement the social-media campaign in line with the reviewed plan and retain evidence of the implementation.

Week 12 also creates the evidence base needed for later **C.M3/BC.D3** analysis and optimisation.

## Core checks

By the end of Week 12, learners should be able to:

- [ ] confirm the refined plan is the implementation reference point;
- [ ] configure available DojoLearn business-profile/campaign features appropriately;
- [ ] present a professional business/campaign identity;
- [ ] apply planned branding consistently;
- [ ] use appropriate tone and messaging;
- [ ] distinguish consistency from identical duplication;
- [ ] quality-check content before publication;
- [ ] check audience/purpose alignment;
- [ ] check policy/privacy/confidentiality considerations;
- [ ] check permissions/copyright considerations where relevant;
- [ ] check accessibility/readability;
- [ ] publish appropriate planned campaign activity;
- [ ] link implementation actions to requirements/objectives;
- [ ] capture implementation evidence contemporaneously;
- [ ] annotate/index evidence meaningfully;
- [ ] identify simulator limitations;
- [ ] record significant deviations from the plan;
- [ ] identify follow-up monitoring requirements.

## C.P5 readiness/evidence indicators

Evidence should demonstrate actual implementation, potentially including profile/configuration evidence, published campaign content, simulator activity and an implementation/evidence log, subject to the assignment and centre's evidence requirements.

## Common misconceptions

- [ ] “My plan proves I implemented the campaign.”
- [ ] “More screenshots automatically mean stronger evidence.”
- [ ] “Every platform should look identical.”
- [ ] “Once content is planned it no longer needs checking.”
- [ ] “If implementation changes, I should hide the difference.”
- [ ] “Any change means the plan was bad.”
- [ ] “I should publish extra content just to create evidence.”
- [ ] “DojoLearn has every feature of a real social platform.”
- [ ] “I can organise the evidence at the end from memory.”

## Evidence sources

Use professional-profile/configuration evidence, pre-publication checks, DojoLearn implementation activity, implementation evidence log, deviation records and published campaign content.

## Transition to monitoring

Before the next stage, learners should know:

1. what campaign activity is currently implemented/live;
2. what activity remains scheduled;
3. the baseline and target values;
4. which metrics/interactions need monitoring;
5. where implementation evidence is stored;
6. which deviations/limitations may affect later interpretation.
