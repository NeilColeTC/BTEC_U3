# DojoLearn Practical — Campaign Implementation Workshop

## Purpose

Implement the reviewed/refined campaign across the selected simulated platform(s) and create reliable evidence of the work completed.

## Stage 1 — Confirm readiness

Before publishing:

- refined plan available;
- selected platform(s) confirmed;
- final baseline/targets available;
- profile configuration checked;
- content/publication plan available;
- community/policy arrangements available;
- planned content ready for quality assurance.

## Stage 2 — Configure

Use DojoLearn to configure available business-profile/campaign features in line with the refined plan. Record any feature the plan expected but the simulator cannot represent.

## Stage 3 — Quality check content

Use the pre-publication checklist before each significant item or planned batch of content.

## Stage 4 — Publish

Publish the appropriate planned campaign content according to the campaign schedule and simulator/lesson conditions.

Do not publish additional content simply to generate more screenshots. Every activity should have a campaign purpose.

## Stage 6 — Check against plan

At the end of the workshop identify:

- activity implemented as planned;
- activity still scheduled;
- any deviations;
- any simulator limitations;
- what data/interaction must be monitored next.

## Evidence discipline

Evidence should show the learner's implementation, not merely the planning document. Capture simulator state/output where permitted and annotate what each item demonstrates.
