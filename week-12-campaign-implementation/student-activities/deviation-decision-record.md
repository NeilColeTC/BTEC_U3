# Activity — Implementation Deviation Decision Record

Use this when implementation differs significantly from the refined plan.

**Plan element:** ______  
**Planned action:** ______  
**Actual issue/evidence:** ______

## Decision chain

**difference → reason/evidence → decision → effect on requirements/objectives → follow-up**

| Question | Response |
|---|---|
| What changed or needs to change? | |
| Why can the original plan not/should not be followed exactly? | |
| What evidence supports the change? | |
| What alternative actions were possible? | |
| What decision was made? | |
| Which requirement/objective is affected? | |
| Does a target, schedule, content item, responsibility or policy element also need updating? | |
| What follow-up/monitoring is required? | |

## Principle

A justified change can demonstrate stronger implementation judgement than blindly following an unsuitable plan. An unexplained change weakens traceability.
