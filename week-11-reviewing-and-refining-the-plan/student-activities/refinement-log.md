## Decision types

- **Accept:** implement the feedback substantially as suggested.
- **Adapt:** respond to the underlying issue but use a different/better solution.
- **Reject/retain:** retain the original decision because it remains better supported.

## Justification prompt

For significant decisions use:

**issue/feedback → requirement → alternatives → consequence → decision → judgement**

## Dependency check

After each change ask whether it affects:

- platform choice;
- content format/message;
- schedule;
- target audience assumptions;
- measures/targets;
- responsibilities/resources;
- community response arrangements;
- policy controls.
