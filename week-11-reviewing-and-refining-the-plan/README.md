# Week 11 — Reviewing and Refining the Plan

**Specification focus:** Learning Aim B — B6  
**Assessment preparation:** B.P4 / B.M2 / BC.D3  
**Practical environment:** DojoLearn social-media simulation

## Week purpose

Week 11 is the quality-assurance gateway between planning and implementation. Learners gather stakeholder feedback, audit the campaign plan against requirements, identify weaknesses or inconsistencies, make controlled refinements and justify what they changed — or deliberately retained.

The central review cycle is:

**plan → test against requirements → stakeholder feedback → analyse → refine/retain → justify → implementation baseline**

## Learning outcomes

Learners should be able to:

1. Review a campaign plan systematically rather than simply proofread it.
2. Gather useful stakeholder feedback against defined questions/criteria.
3. Distinguish feedback from evidence and judgement.
4. Prioritise feedback according to requirements, likely impact and feasibility.
5. Document changes through a review/refinement log.
6. Justify accepted, adapted and rejected feedback.
7. Check traceability from business requirements to planned campaign activity and measures.
8. Prepare a controlled final implementation configuration in DojoLearn.
9. Develop evaluative reasoning towards BC.D3 without prematurely evaluating campaign performance.

## B6 focus

This week concentrates on review, stakeholder feedback, refinement, documented decision-making and final pre-implementation quality assurance.

## DojoLearn practical

Learners prepare the final implementation configuration only after completing the review. They verify settings, platforms, targets and other available campaign configuration against the refined plan and capture a pre-implementation baseline/evidence point.

## Assessment boundary

Review structures and neutral formative examples support the assessment process, but teachers/resources should not decide which feedback a learner must accept or write the learner's final justification. The refined campaign remains the learner's own work.
