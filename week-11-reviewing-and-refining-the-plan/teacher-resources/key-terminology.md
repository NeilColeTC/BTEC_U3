# Week 11 Key Terminology

| Term | Working definition | Why it matters |
|---|---|---|
| Review | Systematic examination of the plan against requirements and quality criteria. | Identifies weaknesses before implementation. |
| Refinement | Controlled improvement or adjustment to a plan following review/evidence. | Converts review findings into better planning. |
| Stakeholder | Person/group with a relevant interest or perspective on the campaign. | Can provide useful feedback, but their view still needs evaluation. |
| Stakeholder feedback | Recorded comments/evidence from a relevant reviewer about the plan. | Supports B6 review and refinement. |
| Feedback question | Prompt designed to obtain useful information from a reviewer. | Focused questions produce more actionable evidence than “do you like it?”. |
| Coherence | Extent to which different parts of the plan support each other. | Prevents disconnected campaign decisions. |
| Feasibility | Whether the plan can realistically be delivered within available constraints/resources. | A theoretically strong plan may still fail operationally. |
| Measurability | Extent to which progress/outcomes can be evidenced against objectives. | Essential for later evaluation. |
| Prioritisation | Ranking issues/feedback according to importance. | Helps focus limited refinement time on high-impact changes. |
| Accept | Implement feedback substantially as suggested. | Appropriate where evidence supports the suggestion. |
| Adapt | Address the issue but use a modified solution. | Useful when the problem is valid but the proposed solution is not optimal. |
| Reject/retain | Decide not to make the suggested change and retain the original approach. | Valid when supported by stronger requirements/evidence. |
| Refinement log | Record of review evidence, decisions, changes and rationale. | Demonstrates a traceable development process. |
| Dependency | Relationship where changing one plan element affects another. | Prevents refinements creating inconsistencies elsewhere. |
| Change control | Managing and documenting changes so the final plan remains coherent. | Mirrors professional project/campaign practice. |
| Implementation baseline | Recorded state immediately before campaign activity begins. | Enables later comparison between planned starting point and outcomes. |
| Evaluative judgement | Weighing evidence, alternatives, consequences and significance to reach a supported conclusion. | Supports progression towards distinction-level reasoning. |
