# BTEC Level 3 Unit 3 — Using Social Media in Business

This repository contains the teaching, learning and assessment-support resources for Pearson BTEC Level 3 Unit 3: **Using Social Media in Business**.

The course is organised as a 17-week programme aligned to the Pearson specification, approved assignment briefs and 2026–27 scheme of work. Practical activities use the purpose-built **DojoLearn** simulation in `NeilColeTC/DojoLearn`.

## Learning aims

- **A** — Explore the impact of social media on the ways in which businesses promote their products and services.
- **B** — Develop a plan to use social media in a business to meet requirements.
- **C** — Implement the use of social media in a business.

## Delivery model

**plan → create → publish → interact → analyse → optimise → evaluate**

Learners use simulated platforms including The Wall, The Pulse, The Grid, The Metronome, The Pin and The Tube. DojoLearn provides a controlled environment for campaign planning, content publication, audience interaction, analytics and optimisation without requiring live public social-media accounts.

## Repository structure

- `curriculum/` — course map, specification map, terminology, resource index and delivery sequence
- `assessment/` — exact criteria map, evidence guidance and grading/readiness checklists
- `templates/` — reusable planning, evidence and review templates
- `teacher-guidance/` — delivery, simulation and assessment-boundary guidance
- `week-01-...` to `week-17-...` — weekly teaching packages
- `repository-audit.md` — whole-repository completion audit and maintenance notes

Each developed teaching week contains a `README.md`, lesson plan, slide content, student activities, teacher resources and assessment checks.

## Assessment structure

### Assignment 1 — Learning Aim A

**A.P1, A.P2, A.M1, A.D1**

### Assignment 2 — Learning Aims B and C

**B.P3, B.P4, B.M2, C.P5, C.P6, C.M3, BC.D2, BC.D3**

Important distinction:

- **BC.D2** — evaluate the plan and use of social media in a business against business requirements.
- **BC.D3** — demonstrate individual responsibility, creativity and effective self-management in the planning and use of social media in a business context.

BC.D3 should therefore be evidenced across the practical process through authentic decision-making, organisation, creativity and professional behaviours, not treated as a second final evaluation criterion.

## Assessment-support principle

Resources use worked examples, neutral scenarios, simulation activities and evidence structures to prepare learners for independent assessment. They should not be used to provide completed responses to live assignment tasks.
