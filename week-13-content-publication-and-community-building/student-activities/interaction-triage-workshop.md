# Activity — Interaction Triage Workshop

For each neutral interaction, classify it and decide the appropriate type of action. Do not assume every negative message should be removed.

## Decision process

**classify → decide → respond/action → policy reason → escalate if needed → record**

| Interaction | Classification | Public response? | Moderate? | Escalate? | Policy reason | What must be recorded? |
|---|---|---|---|---|---|---|
| “What time does the workshop start?” | | | | | | |
| “Really useful post — thanks!” | | | | | | |
| “The instructions are confusing on mobile.” | | | | | | |
| “I registered last week and nobody replied.” | | | | | | |
| “This service costs £50” when the published information says it is free | | | | | | |
| Repeated unrelated promotional links | | | | | | |
| Personal insults directed at another user | | | | | | |
| A user posts account/login information while asking for help | | | | | | |

## Reflection

1. Which interactions need the fastest response and why?
2. Which require authority or information you may not have?
3. Which should remain visible even though they are negative?
4. Which create privacy/security concerns?
5. How does a written policy make these decisions more consistent?
