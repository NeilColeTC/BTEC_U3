## Persistent evidence IDs

The practical sequence uses stable evidence prefixes where useful:

- `IMP-xx` — implementation evidence
- `COM-xx` — community-management/interaction evidence
- `ANA-xx` — analytics findings
- `OPT-xx` — optimisation evidence

These provide a consistent evidence trail from implementation through final evaluation.
