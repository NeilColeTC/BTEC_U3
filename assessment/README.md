# Assessment Support

This folder contains repository-level assessment guidance. Always use the current approved assignment brief and centre/Pearson assessment procedures as the authoritative assessment documents.

## Files

- `criteria-map.md` — criterion wording/summary used by this repository
- `evidence-map.md` — potential evidence types
- `assignment-1-grading-checklist.md` — readiness/grading support for Learning Aim A
- `assignment-2-grading-checklist.md` — readiness/grading support for Learning Aims B/C

## Important distinction

**BC.D2** evaluates the plan and use of social media against business requirements. **BC.D3** demonstrates individual responsibility, creativity and effective self-management. Do not merge these into one generic final-evaluation criterion.
