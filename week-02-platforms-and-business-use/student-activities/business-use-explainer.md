# Activity — Explaining Business Uses

For each A1 business use, develop an explanation rather than a list point.

| Business use | What does the business do? | How does social media enable this? | Why could this benefit the business? | Example/context |
|---|---|---|---|---|
| Create an image/brand | | | | |
| Promote products/services | | | | |
| Communicate with customers | | | | |
| Customer service | | | | |
| Resolve queries/issues | | | | |
| Advertising | | | | |

## Improve the explanation

Weak: **“A shop can use social media for customer service.”**

Rewrite this using:

**use → mechanism → benefit → context/example**

## Challenge

Choose two uses and explain how they could reinforce each other. For example, how might customer communication affect brand image?
