# Contributing

This repository is a curriculum resource. Changes should preserve specification alignment, learner independence and the 17-week progression.

## Before changing a week

1. Check `assessment/criteria-map.md`.
2. Check `curriculum/specification-map.md` and `curriculum/course-map.md`.
3. Keep examples neutral where live assessment risk exists.
4. Verify DojoLearn functionality before naming specific simulator features/metrics.
5. Preserve assessment boundaries and evidence authenticity.

## Style

Use Markdown, clear headings, tables where they improve classroom use and consistent criterion notation.

## Criterion caution

Do not confuse **BC.D2** evaluation with **BC.D3** responsibility/creativity/self-management.
