# Week 15 Key Terminology

| Term | Working definition | Why it matters |
|---|---|---|
| Optimisation | Evidence-led adjustment intended to improve campaign performance against a relevant objective. | Central to C.M3. |
| Hypothesis | Testable proposed explanation/prediction connecting a change to an expected outcome. | Makes the reason for an optimisation explicit. |
| Variable | Feature/factor that can change or be measured. | Identifies what is deliberately altered. |
| Independent variable | Factor deliberately changed during a test/comparison. | Helps clarify what the optimisation is testing. |
| Dependent measure | Outcome/metric monitored after the change. | Provides evidence for judging the effect. |
| Controlled change | Deliberately changing a defined factor while keeping other major conditions as similar as reasonably possible. | Supports more useful before/after interpretation. |
| Confounding variable | Other changing factor that could explain the observed result. | Prevents overclaiming causation. |
| Before state | Preserved content/configuration/performance evidence prior to optimisation. | Required for traceable comparison. |
| After state | Revised content/configuration/performance evidence following optimisation. | Enables comparison with the original. |
| Before/after comparison | Examination of relevant measures before and after a change. | Helps judge whether the optimisation appears beneficial. |
| Retain | Keep the optimisation after reviewing evidence. | One valid evidence-led decision. |
| Refine further | Make another justified controlled improvement. | Supports iterative optimisation. |
| Revert | Return to the previous approach because evidence does not support the change. | Demonstrates evidence-led decision-making rather than attachment to a change. |
| Insufficient evidence | Available evidence is not strong enough to support a reliable judgement. | A valid conclusion that prevents fabricated success claims. |
| Attribution | Judgement about what may have contributed to an observed result. | Must account for confounders and limitations. |
| Iteration | Repeated cycle of implementation, measurement and improvement. | Reflects professional optimisation practice. |
