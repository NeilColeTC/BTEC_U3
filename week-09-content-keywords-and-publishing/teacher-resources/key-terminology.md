# Week 9 Key Terminology

| Term | Working definition | Why it matters |
|---|---|---|
| Keyword | Relevant word/phrase used in content or research to communicate topic/audience intent. | Helps content remain relevant and discoverable. |
| Hashtag | Platform-supported keyword marker used to categorise/connect content where appropriate. | Can support discovery/context but should be relevant. |
| Tag | Platform feature referencing another account/entity. | Can create relevant connections but should not be indiscriminate. |
| Keyword stuffing | Excessive/artificial repetition of keywords. | Can reduce clarity, professionalism and usefulness. |
| Content calendar | Planned schedule of campaign content and associated decisions. | Turns strategy into an implementable sequence. |
| Content ID | Consistent identifier assigned to planned/published content. | Supports traceability across planning, implementation and analytics. |
| Publishing schedule | Planned dates/stages/frequency for campaign content. | Supports feasibility and coordinated implementation. |
| Content sequence | Order in which campaign messages appear. | Some content prepares users for later action. |
| CTA | Call to action: prompt for an intended audience next step. | Connects content with action-oriented objectives. |
| Frequency | How often content/activity is planned. | Affects visibility, repetition and resource demand. |
| Platform constraint | Limitation imposed by available features/formats/workflow. | May require justified adaptation before implementation. |
| Draft | Pre-publication version used for checking/refinement. | Supports quality assurance before the live campaign. |
