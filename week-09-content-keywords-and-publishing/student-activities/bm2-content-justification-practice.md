# B.M2 Formative Practice — Content and Scheduling Decisions

**Neutral practice scenario — not Assignment 2 evidence.**

A fictional local library is promoting free evening workshops. It needs to raise awareness, communicate useful information and encourage visits to a programme-information page. Staff time for content production is limited.

## Task

Justify:

- two content purposes/formats;
- one keyword/hashtag approach;
- one CTA decision;
- a realistic publishing frequency/sequence.

Use:

**decision → requirement/evidence → audience/objective link → benefit → constraint/trade-off → judgement**.

## Peer-check

- [ ] Decisions link to requirements/objectives.
- [ ] Audience relevance is explained.
- [ ] Platform/content evidence is used.
- [ ] Resource constraints are considered.
- [ ] At least one trade-off is recognised.
- [ ] The conclusion is contextual rather than preference-led.
