# Week 16 Retrieval Quiz — Indicative Answers

1. A need, constraint or outcome the campaign must address for the business/client.
2. Defined condition/measure used to judge whether an objective has been achieved.
3. Ability to connect evidence and decisions back to requirements/objectives.
4. Recorded starting state before implementation.
5. Intended performance level/outcome for a relevant campaign measure.
6. Factor restricting what can safely be concluded from available evidence.
7. Evidence-led adjustment intended to improve performance against an objective.
8. Another changing factor that could explain an observed result.
9. Analysis examines relationships/patterns and possible meaning; evaluation reaches a supported judgement against relevant criteria.
10. Because different objectives use different success measures and evidence can show mixed performance.

Use diagnostically. Learners must make their own assessed judgements.
