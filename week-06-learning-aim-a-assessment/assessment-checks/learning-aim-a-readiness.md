# Learning Aim A — Assessment Readiness and Progress Check

## Criteria

- **A.P1**
- **A.P2**
- **A.M1**
- **A.D1**

## Learner readiness

### Research

- [ ] Learner has relevant evidence for the business/social-media context required by the assignment.
- [ ] Audience/platform claims have traceable evidence.
- [ ] Sources show appropriate authority/relevance/currency.
- [ ] Learner can distinguish evidence from assumption.

### Command terms

- [ ] Learner can explain the difference between explain, assess and evaluate.
- [ ] Learner's planned reasoning matches the criterion demand.

### A.P1/A.P2

- [ ] Evidence is sufficient to support explanation rather than listing.
- [ ] Business use and audience considerations are both addressed as required.

### A.M1

- [ ] Learner has alternatives/factors that can be meaningfully assessed.
- [ ] Strengths/limitations are contextual rather than generic.
- [ ] Judgements are supported.

### A.D1

- [ ] Learner can connect interaction and promotion with target audience/business purpose.
- [ ] Relevant A3 risks/issues are incorporated.
- [ ] Consequences/significance are considered.
- [ ] Mitigation/conditions can inform the overall judgement.
- [ ] Conclusion is reasoned rather than asserted.

## Workshop status

Mark each learner:

- **Ready for independent production**
- **Ready with organisational support**
- **Research gap to address**
- **Command-term misconception to address**
- **Additional supervised time required**

## Teacher feedback boundary

Use this checklist to identify gaps. Do not complete missing analysis, evaluation or conclusions for the learner.

## End-of-week transition

Learning Aim A should now be sufficiently taught and supported for Assignment 1 production. Week 7 begins Learning Aim B campaign planning.
