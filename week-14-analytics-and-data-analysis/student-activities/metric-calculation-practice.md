# Activity — Metric Calculation Practice

Use this fictional dataset for formative calculation practice.

| Post | Exposure | Interactions | Intended actions |
|---|---:|---:|---:|
| A | 1000 | 50 | 8 |
| B | 200 | 40 | 12 |
| C | 600 | 48 | 6 |

## Task 1 — Raw ranking

Rank the posts by total interactions.

## Task 2 — Interaction rate

For this exercise use:

**interaction rate = interactions ÷ exposure × 100**

Calculate the rate for A, B and C.

## Task 3 — Action rate

For this exercise use:

**action rate = intended actions ÷ exposure × 100**

Calculate each rate.

## Task 4 — Interpret

1. Which post has the largest raw interaction count?
2. Which has the strongest interaction rate?
3. Which has the strongest action rate?
4. Why would “Post A is best because it got 50 interactions” be incomplete?
5. If the campaign objective prioritised intended actions, which metric deserves greatest weight and why?

## Task 5 — Limitations

Identify three pieces of context you would want before claiming that the content itself caused the differences.
