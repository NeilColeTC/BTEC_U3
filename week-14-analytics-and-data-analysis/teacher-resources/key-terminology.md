# Week 14 Key Terminology

| Term | Working definition | Why it matters |
|---|---|---|
| Analytics | Collection and examination of data to understand campaign activity/performance. | Provides the evidence required for C4/C.P6. |
| Metric | Defined quantitative measure of an aspect of campaign activity/performance. | Allows specific aspects of performance to be compared. |
| Raw count | Total number of recorded events/actions. | Useful but can mislead when opportunities/exposure differ. |
| Rate | A measure relating an outcome to a relevant denominator, often expressed as a percentage. | Can support fairer comparisons. |
| Denominator | The value an outcome is divided by when calculating a rate. | Determines what the percentage actually represents. |
| Percentage change | Relative change between an original and new value: (new-original)/original × 100. | Useful for baseline comparison when mathematically valid. |
| Baseline | Recorded starting state before campaign implementation. | Enables comparison of change over time. |
| Target | Intended level/outcome for a campaign measure. | Provides a benchmark for progress. |
| KPI | Key performance indicator: a measure selected as particularly important to an objective. | Helps focus analysis on meaningful outcomes rather than every available number. |
| Engagement/interaction | Audience action involving campaign content/account. | Central evidence for content/community performance where relevant. |
| High-performing content | Content performing strongly against a relevant objective/comparison. | Helps identify potentially effective campaign approaches. |
| Low-performing content | Content performing weakly against a relevant objective/comparison. | Provides evidence for investigation/optimisation. |
| Intended audience | Audience the campaign was planned to reach/influence. | Provides the benchmark for audience analysis. |
| Actual audience | Audience evidenced as having been reached/engaged, to the extent available data supports this. | Allows audience fit to be examined. |
| Pattern | Repeated relationship/trend across observations. | Generally more informative than a single isolated result. |
| Anomaly | Observation that differs notably from the surrounding pattern. | May reveal an issue/opportunity requiring investigation. |
| Correlation | Association between variables/events. | Can suggest a relationship worth investigating. |
| Causation | Evidence that one factor produced an effect. | Should not be claimed from simple campaign correlations without support. |
| Data limitation | Feature of the data that restricts what can safely be concluded. | Essential for credible interpretation. |
| Vanity metric | Impressive-looking measure that may have weak relevance to the actual objective. | Prevents analysis being driven by large but unimportant numbers. |
