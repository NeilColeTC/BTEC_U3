# Week 14 — Analytics and Data Analysis

**Specification focus:** Learning Aim C — C4  
**Assessment preparation:** C.P6  
**Practical environment:** DojoLearn social-media simulation

## Week purpose

Week 14 turns the campaign evidence accumulated during Weeks 12–13 into systematic analysis. Learners gather campaign analytics, examine interaction with individual posts, compare intended and actual audiences, identify high- and low-performing content and use evidence rather than intuition to describe campaign performance.

The central analytics cycle is:

**question → select metric/evidence → collect → organise → compare → interpret → qualify → conclude**

## Learning outcomes

Learners should be able to:

1. Gather relevant campaign analytics from DojoLearn accurately.
2. Distinguish raw counts from rates, comparisons and interpretations.
3. Analyse interaction with individual campaign posts/content.
4. Compare content performance fairly using relevant metrics.
5. Identify high- and low-performing content using evidence and appropriate context.
6. Compare the intended target audience with the actual audience evidence available.
7. Compare current performance with baseline and campaign targets where supported.
8. Identify patterns, anomalies and limitations in campaign data.
9. Avoid unsupported causal claims and vanity-metric conclusions.
10. Produce an evidence-based C.P6 analysis that can feed Week 15 optimisation and Week 16 evaluation.

## C4 focus

This week concentrates on gathering and interpreting campaign data, individual-post interaction, intended-versus-actual audience comparison and identification of high- and low-performing content.

## DojoLearn practical

Learners extract available simulated analytics, create a structured campaign data table, calculate relevant derived measures where meaningful, compare posts/platforms/audiences and create an analytics evidence pack.
